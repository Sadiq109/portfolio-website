# Portfolio website

A single-page personal portfolio for Sadiq Mohamud, a University of Minnesota Twin Cities student pursuing bachelor's degrees in Computer Science and Information Technology Infrastructure.

## Features

- Project links for software, data and security work
- Responsive layout
- Dark mode toggle
- Contact links for GitHub, LinkedIn and email

## Run locally

Open `index.html` in a browser. The site uses plain HTML, CSS and JavaScript with no build step.

## Status

This repository is private while the content and project list are being updated. Do not publish it until the personal information and linked projects have been reviewed.
